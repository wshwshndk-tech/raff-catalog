# رفّ — تجربة أولية لخدمة كتالوجات المتاجر

هذا نموذج عمل وخدمة قابلان للاختبار، **وليس مشروعًا يدرّ دخلًا حاليًا**.

## الملفات

- `public/index.html`: صفحة تعريف بالخدمة وعرض سعر **مقترح** 199 ر.س شهريًا.
- `public/demo.html`: مثال تفاعلي يعمل محليًا، لا يرسل طلبات حقيقية.
- `builder.html`: أداة مجانية محلية لتوليد كتالوج HTML فعلي لعميل (يُدخل صاحب المشروع رقم واتساب المتجر بعد الحصول على إذنه).

## العرض التجاري المبدئي

- 199 ريال/شهر لكل متجر صغير.
- باقة مبدئية: كتالوج جوال حتى 30 صنفًا، إعداد أولي، وتحديثان شهريًا تشمل كل منهما حتى خمسة تغييرات للأصناف/الأسعار، على أن تؤكد هذه الحدود في عقد الخدمة قبل البيع.
- دون رسوم دفع أو تكامل مخزون أو توصيل أو تعهد بزيادة مبيعات؛ المتجر يتعامل مع المشترين بنفسه.
- هدف 5 عملاء مشتركين = 995 ريال إيرادات شهرية إجمالية، قبل أي مصروفات والتزامات نظامية.

## طريقة العمل

1. افتح `builder.html` في المتصفح.
2. أدخل اسم المتجر ووصفه ورقم واتساب **الخاص بالمتجر وبموافقته**.
3. أدخل المنتجات في الأسطر الجاهزة، ثم اضغط «تنزيل كتالوج جاهز».
4. اختبر الملف الناتج على جوال واختبر زر واتساب باستخدام رقمك التجريبي قبل النشر.
5. انشر ملفات المتجر عبر استضافة مناسبة، بعد اتفاق واضح مع العميل.

## نشر صفحة التجربة على Render

الخيار الأفضل: مستودع GitHub جديد **منفصل** عن مستودع `badr-radar`، يضم الملفات.

- نوع الخدمة: Static Site.
- Branch: `main`.
- Build command: `mkdir -p dist && cp -R public/. dist/`
- Publish directory: `dist`.
- تفعيل Auto Deploy اختيارياً.

خدمة Render للمواقع الثابتة متاحة بلا رسوم نشر أساسية، لكنها تدخل ضمن حدود الاستهلاك الشهري؛ تأكد من إعدادات الفوترة لتجنب الرسوم الإضافية.

**لا تستخدم GitHub Pages لاستضافة موقع تجاري**: سياستها لا تسمح بأن يكون الاستخدام الأساسي موقعًا تجاريًا أو SaaS.

## ما يلزم قبل الإعلان أو استقبال الأموال

- وسيلة تواصل تجارية معتمدة يوافق صاحبها على نشرها.
- شروط خدمة بسيطة واضحة (نطاق العمل، التعديلات، فترات التسليم، سياسة الإلغاء والاسترجاع، المسؤوليات والخصوصية).
- وسيلة تحصيل نظامية وحساب بنكي مناسب عند وجود أول عميل، وفق الإجراءات الواجبة لنشاطك في السعودية.
- اختبار طلب عميل حقيقي: لا تُسجّل أي مدفوعات أو اشتراكات أو إيرادات حتى تتحقق بالفعل.

## التحقق من السوق بأقل تكلفة

ابدأ بعرض 3 نماذج مجانية مخصصة لمتاجر تسمح لك باستخدام بياناتها، ثم احصل على تقييم صريح بشأن السعر والاشتراك. بعدها خُذ اشتراكًا تجريبيًا مدفوعًا إن وافق العميل. لا ترسل رسائل جماعية عشوائية.
